省水小碗 — AI Energy & Water Transparency Extension

Prototype · Developer Mode Only 2026 – Present

A Manifest V3 browser extension that makes the hidden energy and water cost of LLM conversations visible in real time. Every time you send a message to an AI chatbot, a small animal walks up to a water bowl on the popup and "drinks" — a lightweight, playful way of making an invisible cost visible.

Repositioned mid-build from a gamified behaviour-change tool into an education-first transparency tool, once early testing showed the gamification wasn't actually changing anyone's usage. The honest goal is awareness, not enforced restraint — so the extension never blocks, nags, or scores you. Every energy/water estimate is grounded in a published research source (Jegham et al., 2025) rather than an invented number.

Current status: this is a working prototype, tested locally in developer mode. It has not yet been submitted to the Chrome Web Store, so for now it needs to be installed manually from the downloaded files below.
Download Extension (.zip) ↓

How to install (developer mode)

  1. Download and unzip the file above.
  2. Open chrome://extensions in Chrome.
  3. Turn on "Developer mode" in the top-right corner.
  4. Click "Load unpacked" and select the unzipped folder.
  5. The 省水小碗 icon will appear in your toolbar — click it to see the water-drinking animation while you chat with an AI.
